# Green-triangle-page-V2
I created this page to test my skills; it includes various functions and features, but the main focus was the design, as I am trying to improve in that area. Languages ​​such as JavaScript and CSS were used for the design, while HTML was used for the buttons and functions.



About the Project (WebOS V2)To be honest, I didn't set out to reinvent the wheel or create something entirely groundbreaking. My true goal was to build a highly polished, clean, and minimalist interface where the user can instantly access essential features. As the saying goes: doing the basics exceptionally well is far better than doing something complex poorly.Design & Aesthetics (CSS)I put a lot of work into the visual style, writing nearly 300 lines of custom CSS. I chose a retro-hacker, cyberpunk aesthetic featuring a solid black background paired with vibrant neon-green elements to make the geometry and text pop. It is intentionally non-cluttered and minimalist, yet highly detailed in its textures and glow effects.Features & System LogicThe interface is fully functional and includes:Time Utilities: An updated calendar and a precise stopwatch/timer.Hacker Notes: A minimalist notepad area for quick text input.Search Bar: A clean portal to navigate and search external links easily.Arcade Mini-Game: A custom-coded "Dino-style" survival game where you control a triangle and must jump over oncoming obstacles. This mechanic took a lot of effort to program and balance.Code Architectureindex.html: Defines the layout, structural bones, windows, and core buttons.style.css: Powers the entire visual identity, neon effects, and polished layout.index.js: Handles 100% of the system logic, widget tracking, and the physics for the mini-game.



Major Challenge:The main challenge for me was definitely the UI design. I am still learning a lot about programming, but to enrich the visual style, I pushed myself to create a distinct retro-hacker, cyberpunk aesthetic. In the end, I think I achieved exactly the result I was aiming for. On the coding side, my biggest technical obstacle was the mini-game. Having to create and manage so many constants and variables got a bit confusing at one point, but I managed to figure it out, untangle the logic, and successfully complete the entire mechanic.Main Thing People Need to Know:The most important thing to know is that this interface is designed to be a quick, stylish, and fun portal. You can open the windows to access shortcuts for everyday sites like YouTube, Google, and ChatGPT, or you can just hop into the mini-game tab for a bit of entertainment. It is built to give the user a sleek, immersive hacker-vibe workspace while keeping everything fast and functional.
